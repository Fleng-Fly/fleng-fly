## Design pillars

1. **Premium dark** — deep, calm background; content is the focus.
2. **Focused learning** — minimal chrome, clear next action, no clutter.
3. **Progress you can feel** — visible streaks, XP and completion states.
4. **Trustworthy** — accessible contrast, predictable interactions.
5. **Alive but restrained** — subtle gradients, glass, purposeful motion.

## Non-negotiables

- Dark theme is the default (light theme is optional later, not required now).
- Purple/violet primary with blue/cyan accents; accent color is meaningful, not
  decorative noise.
- Readable contrast (target WCAG AA), keyboard focus visible.
- Motion respects `prefers-reduced-motion`.
