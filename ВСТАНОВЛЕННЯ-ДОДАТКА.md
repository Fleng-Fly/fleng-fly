# Доступ до Fleng

Відкрий сайт Fleng у браузері на комп’ютері або телефоні й увійди у свій
обліковий запис. Для уроків і збереження прогресу потрібні інтернет і сервер.
На іншому пристрої використовуй той самий сайт та обліковий запис.

Пропозиції завантаження й встановлення вилучено з інтерфейсу.
Старий `/install.html` збережено як довідку про доступ і прогрес.
Маніфест, іконки та service worker залишаються.

Локальний запуск: `npm run dev` → `http://localhost:3001`.
На Windows також є `START-WINDOWS.cmd`.
Деталі: `docs/pwa-installation.md`.
