# Fleng для Windows, Linux, Android та iPhone

Цей архів — оновлений проєкт із встановлюваним вебдодатком (PWA).
Він не містить окремих EXE, APK чи IPA.

1. Онови свій сервер файлами з цього проєкту за `docs/deployment.md`.
2. Відкрий на потрібному пристрої `https://твій-домен/install.html`.
3. Виконай інструкцію для своєї системи. Після встановлення з’явиться іконка Fleng.

| Пристрій | Як встановити |
| --- | --- |
| Windows | Відкрий сайт в Edge/Chrome → «Встановити Fleng» або меню встановлення браузера. |
| Linux | Відкрий сайт у Chrome/Chromium із підтримкою PWA → «Встановити Fleng». |
| Android | Chrome → «Встановити додаток» або меню ⋮ → додавання на головний екран. |
| iPhone | Safari → «Поширити» → «На початковий екран» → «Додати». |

Для входу, уроків та прогресу потрібні інтернет і працюючий сервер.
Обліковий запис і прогрес зберігаються на тому сервері, до якого ти підключився.
Публікацію на хостингу автоматично не виконано.

На своєму ПК можна перевірити через `npm run dev` →
`http://localhost:3001/install.html`. На Windows також є `START-WINDOWS.cmd`.
Для встановлення на телефон потрібна доступна HTTPS-адреса.

Деталі: `docs/pwa-installation.md`.
