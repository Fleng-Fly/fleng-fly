# Fleng — доступ через браузер

Fleng тепер лише вебсайт. Окремого додатка, EXE або PWA-встановлення немає.
Відкрий адресу чинного хостингу. Для локальної перевірки запусти
`npm run dev` та відкрий http://localhost:3001.

Старий `/install.html` перенаправляє до Dashboard; браузерний кеш Fleng
та його service worker прибираються без видалення акаунтів чи прогресу.
