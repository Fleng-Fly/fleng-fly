# Courses

Course stores a globally unique slug, title, description, level, position and is_published. Levels accept internal introductory A0 plus CEFR A1–C2. Ordinary catalog reads show only published courses and lessons, ordered by position; optional level filtering is supported.

Progress exposes published course totals and started/completed lesson counts. No payment entitlement, enrollment lock or enforced prerequisite access system exists. C1/C2 schema acceptance does not mean corresponding curriculum content exists.

A0 is not an official CEFR certification level. Five A0–B2 main courses remain drafts; two legacy seeded courses remain separate. See [catalog API](../03-backend/catalog-api.md) and [curriculum](curriculum-a0-b2.md).
