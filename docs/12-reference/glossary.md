# Glossary

| Term | Meaning in Fleng |
| --- | --- |
| FastAPI | Python ASGI framework serving API/static files |
| SQLAlchemy | Async ORM/query layer |
| Alembic | Versioned database schema migrations |
| JWT | Signed short-lived access credential |
| Refresh token | Opaque rotating HttpOnly credential stored hashed |
| SSE | HTTP event framing; Fleng uses POST fetch |
| OpenRouter | Optional backend-only AI provider |
| CEFR | Proficiency framework; schema accepts A1–C2 |
| A0 | Internal introductory label, not official certification |
| VocabularyItem | Owned saved word/review schedule |
| CourseVocabularyItem | Shared word linked to course/its level |
| FlashcardSession | Owned JSON card snapshot/completion |
| Curriculum Validator | Offline structural/grader/evidence pipeline |
| Draft | Unapproved/unpublished source content |
| Seed | Repeatable legacy catalog insertion/update |
| Idempotency | Repetition does not duplicate intended persisted effect |
| Migration | Reviewed schema revision transition |
| XP | Exercise points awarded at most once/user/exercise |
| Grading | Server comparison or nonobjective learner self-assessment |
| testReady | Flag derived from completed flashcard status |
| words_for_test | Owned completed-snapshot handoff, not a test grader |
| Canonical SHA | Validated content hash for publication acknowledgement |
| Raw SHA | Source-byte hash guarding normalization copies |
| Provenance | Evidence identity, source/license/attribution |
