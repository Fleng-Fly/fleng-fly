# Ai tutor

Chat accepts message, optional owned conversationId, visible lessonId/exerciseId, correctGrammar and requestId. Clients cannot submit a system role or provider credentials. Server context understands A0–C2, but generated content is not proficiency certification.

The Dashboard/Lessons floating assistant supports history/new chat, incremental responses and lesson hints. No standalone AI Tutor page exists. Generated exercises return practiceOnly=true and are not persisted graded catalog exercises or XP sources.

Provider answers can be incorrect. Prompt boundaries/output validation do not prove linguistic truth. Never use output automatically to alter answer keys/publication/authorization.
