FLENG — вебверсія 2026.11.16-web.3

Це вихідний код сайту з дизайном за твоїм архівом Figma та пакетним прогресом курсу.
Додаток, EXE і встановлення PWA не потрібні.

ПЕРЕГЛЯД ЗМІН
Відкрий FLENG-REVIEW.md: там API, змінені файли, тести й обмеження.
Нових commit/push і публікації цієї версії не виконано.

ЛОКАЛЬНИЙ ЗАПУСК
1. Розпакуй весь архів в окрему папку.
2. У CMD:
   cd /d "ШЛЯХ-ДО-ПАПКИ\Fleng-Website"
   npm run dev
3. Відкрий http://localhost:3001
Python 3.11+ і Node.js 20+ потрібні для локального запуску.
Збережи свою .env і базу перед перенесенням старого локального проєкту.

ПУБЛІКАЦІЯ
Після твого підтвердження можна використати scripts\UPDATE-SITE.cmd.
Він перевіряє Git-копію C:\Users\Roman\Fleng-GitHub, створює резервну гілку,
застосовує website.patch, робить commit і push у main без force.
Не запускай його для простого перегляду: він публікує код у GitHub.
Після погодженого push потрібне розгортання існуючих Render / Netlify сервісів.
Після розгортання /version.json має показувати 2026.11.16-web.3.
Деталі, доступи, існуюча база та секрети залишаються в твоєму середовищі.
