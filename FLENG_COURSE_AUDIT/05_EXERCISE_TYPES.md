# Підтримувані типи завдань

## Завдання уроків, які можна використати в новій програмі

Усі вправи уроків мають UUID, slug, UUID уроку, позицію, тип, текст питання і бали. Публічний API повертає `id, slug, position, type, prompt, points` та умовні поля `options, letterTiles, instruction, hint`. Типи в таблиці відповідають реальним маршрутам `lessons/{slug}/start|progress|submit|self-check/preview`. Формат у прикладах показує суттєві поля джерела. [Схеми](../backend/app/modules/exercises/schemas.py), [модель](../backend/app/db/models.py).

| Тип або форма | Дані й обов’язкова авторська частина | Принцип, перевірка та межі | Реальний приклад |
| --- | --- | --- | --- |
| Один правильний вибір — `single_choice` | `options: [{id,text},…]`, `correct_option_id`; в авторському базовому форматі також `phase, explanation, points: 1` і рівно три опції | UI передає ID опції. Сервер перевіряє, що ID існує, і порівнює з одним ключем. Вибір у пропуску, питання до тексту й двобічні перевірки словника користуються одним механізмом. | `fleng-a0-hello-practice-1`: `I ___ Eva.`, `am/is/are`, ключ `1` → `am`. |
| Коротка відповідь — `text` | `accepted_answers: [string,…]` для реального оцінювання, `prompt`, `explanation` у доповненні. Для форм доповнення список до 6, жодної `model_answer` | Порівнюються нормалізовані рядки. Цільова відповідь не виводиться з правил граматики. API відхиляє порожнє введення, загальна межа 2000 символів. | `greetings-and-introductions-q2`: відповідь на `Nice to meet you`, прийняті серед іншого `nice to meet you too`, `you too`, `likewise`. |
| Пропуск (форма `text`) | `kind: fill_gap`, `prompt` з `___` й допустимі фрагменти | Потрібно вводити фрагмент. Валідація шаблону джерела перевіряє позначку пропуску, а не граматику речення. | `fleng-a1-routines-extra-1`: `She ___ breakfast at seven. (have)` → `has`. |
| Порядок слів (форма `text`) | `kind: word_order`, рядок `Put the words in order to make a sentence: … / …`, допустимі цілі речення | Учень друкує речення. Імпортер порівнює токени лише першого еталона. Перевірка відповіді працює як для іншого `text`. Треба задати контекст, якщо порядок допускає різні змісти. | `fleng-a2-past-actions-extra-2`: приймає `We arrived at the station late` і `We arrived late at the station`. |
| Переклад (форма `text`) | `kind: translate`, рядок `Translate into English:`, переклад і допустимі відповіді | Точний список нормалізованих відповідників. Історична автоінструкція каже «це слово», навіть коли prompt містить ціле речення. Варіанти регістру і пунктуації не тестуються окремо. | `fleng-a1-food-extra-3`: `«хліб» → bread`. Seed `greetings-and-introductions-extra-6` містить переклад речення. |
| Складання слова літерами (форма `text`) | `letter_tiles: {pattern, letters}`, `accepted_answers`. `_` позначає слот, решта символів фіксовані | Плеєр збирає слово натисканням, клавіатурою або перетягуванням. Сервер контролює довжину, фіксовані літери та кількість використань кожної плитки, потім застосовує перевірку `text`. Базовий JSON-імпортер не приймає `text`; наявний seed підтримує конфігурацію. | `present-perfect-practice-q2` (B1, лише ілюстрація) має `pattern: b__n`, банк `a,e,o,e`, відповідь `been`. У перевірених рядах A0–A2 плиток уроку немає. |
| Самоперевірка — `self_check` | `model_answer`, в авторському `kind: write` без `accepted_answers`. Запит має текст і `selfAssessment: correct/incorrect` | Після введення непорожнього тексту учень відкриває зразок і сам оцінює. Сервер зберігає вибір. Придатне для продукції й рефлексії, незалежного оцінювання граматики або CEFR не здійснює. | `fleng-a2-travel-problem-extra-4`: ввічливе прохання до адміністратора готелю, зразок `Could you help me, please? My room is not available.` |

Для `text` сервер застосовує NFKC, уніфікує типографічні апострофи, замінює частину пунктуації пробілами, стискає пробіли і застосовує casefold. Апостроф у `I'm` та дефіси зберігаються. Синоніми, перестановки чи скорочення проходять лише за наявності в списку. Фронтенд може автоматично перевіряти непорожній текст після 1,5 с паузи, з урахуванням IME. Це важливо для багатослівних завдань. [Нормалізація](../backend/app/modules/exercises/grading.py), [автоперевірка](../frontend/js/auto-check.js), [інструкції](../backend/app/modules/exercises/instructions.py).

## Суміжні механізми

| Механізм | Дані і фактична перевірка | Приклад і обмеження |
| --- | --- | --- |
| Mixed Practice — картки | Персональне слово з `id, word, translation, example`. Учень відкриває переклад і позначає, чи згадав. API review отримує `remembered` й ID спроби. | Після збору `hello` учень бачить `привіт`. Немає незалежного тесту значення. |
| Mixed Practice — вибір перекладу | Фронтенд бере переклад із персонального словника, додає до трьох відмінних рядків зі свого пулу, перемішує й перевіряє вибір. | `hello` → `привіт`. У пулі мають бути різні переклади. Синоніми з різними рядками можуть створити хибний дистрактор. |
| Mixed Practice — введення | Переклад як стимул, точний нормалізований англійський рядок як ціль. JS застосовує NFKC, trim, пробіли й малий регістр. | `ручка` → `pen`. Набір альтернатив, як у серверних `accepted_answers`, відсутній. |
| Mixed Practice — літери | Для простих ASCII-слів 2–24 літери, відкривається кожна третя літера з першої, решта в банку. Порівнює з фактичним словом. | `pen` → `p__`; фрази, діакритика й дефіси випадають з цього формату. |
| Сесії карток API | `flashcard_sessions` знімком бере до 10 слів із `course_words` за фільтром або з `my_words`; стан `active/empty/completed`. | Після completion endpoint віддає ті самі `wordId, word, translation, example` для наступної дії. Окремий автоматичний іспит у цій сесії відсутній. |
| Placement Test | Приватний банк із `id, level, skill, prompt, options, correct_option_id, explanation` і доступним `explanation_uk`; знімок спроби і незмінні ID виборів/пропусків. Сервер рахує оцінку після проходу. | `q01` перевіряє форму `is` для підмета третьої особи однини. Загалом 36 MC, тест незалежний від курсу, без XP. Результат дає обмежений орієнтир A1–B2. |
| Читання в уроці | Текст у `Lesson.theory` і питання через звичайний `single_choice`, `text` або `self_check`. | Наприклад, діалог про бронювання в A2. Окремий Reading-маршрут видалено. Старі таблиці Reading не означають активний тип завдань. |

У Mixed Practice оцінка зберігає повторення особистого слова (1 день після помилки, 7 після успіху за чинним правилом). Пропуск лише просуває локальний сценарій, оцінка за нього не записується. Course Words відкриває наявний Mixed Practice, що працює з персональним словником. Озвучення слів браузером існує, але не становить оцінюваного аудіювання чи перевірки вимови. Fleng AI дає допомогу, проте не підміняє перевірку. [Mixed Practice](../frontend/js/vocabulary.js), [сесії карток](../backend/app/modules/vocabulary/flashcards.py), [банк Placement](../backend/app/db/content/placement-v1.json).
