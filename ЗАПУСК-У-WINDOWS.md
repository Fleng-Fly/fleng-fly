# Як запустити Fleng у Windows

## Перший запуск

1. Установи Python 3.11 або новіший. Увімкни **Add python.exe to PATH**
   під час встановлення.
2. Установи Node.js 20 або новіший.
3. Розпакуй ZIP повністю. Відкрий папку з `package.json`, `frontend`,
   `backend` і `START-WINDOWS.cmd`.
4. Двічі натисни `START-WINDOWS.cmd`. Він встановить залежності,
   підготує базу та запустить сайт. Перший запуск потребує інтернету.
5. Дочекайся повідомлення `Uvicorn running`. Відкрий
   <http://localhost:3001> у браузері.
6. Зареєструй акаунт. Відкрий **Courses → Everyday Conversations →
   Present perfect practice**, щоб спробувати всі три формати завдань.

Залишай вікно запуску відкритим. Для зупинки натисни Ctrl+C.

## Запуск командами

У папці з `package.json` натисни Alt+D, введи `cmd` та натисни Enter.
Виконай по черзі

```cmd
npm run setup
npm run dev
```

Setup також оновлює залежності у вже створеному Python-оточенні, зокрема
встановлює `tzdata` для підтримки часових поясів у Windows.

## Якщо в тебе вже була база Fleng

Онови файли в папці чинного проєкту й виконай

```cmd
npm run setup
npm run db:migrate
npm run db:seed
npm run dev
```

Міграція додає налаштування літерних вправ. Seed оновлює демонстраційний
каталог за slug та додає урок Present perfect practice. Облікові записи,
подані відповіді та XP зберігаються. Назви й вміст демонстраційних курсів,
які ти редагував вручну, seed запише за версією з `backend/app/db/seed.py`.

## Як працюють завдання

- Натисни **Check answer**, щоб перевірити відповідь. Урок покаже результат
  попереднього завдання та відкриє наступне незавершене.
- Спочатку йдуть питання без спроб. Помилки повторюються після них,
  доки не відповіси правильно.
- Якщо залишилося одне питання з помилкою, воно лишається для нової спроби.
- Перетягуй плитки у порожні комірки. Скидання поза вільною коміркою
  залишає плитку на попередньому місці.
- На телефоні натисни літеру, потім порожню комірку. Натискання заповненої
  комірки повертає її літеру до набору.
- Письмове завдання перевіряється за заданою відповіддю. Регістр і зайві
  пробіли ігноруються.
- За правильно виконане завдання XP нараховується один раз.
- У старих вправах Self-check кнопка **I need practice** залишає завдання
  для повторення. **I got it right** завершує його.

## Якщо виникла помилка

**'.venv' is not recognized.** Онови `package.json` та скопіюй
`scripts/backend.mjs` з цього архіву в проєкт. Це виправляє npm-команди
міграцій і seed для Windows. Для негайного запуску виконай з папки проєкту

```cmd
cd backend
.venv\Scripts\python.exe -m alembic upgrade head
.venv\Scripts\python.exe -m app.db.seed
cd ..
npm run dev
```

**ENOENT або C:\package.json.** Відкрий CMD у папці з `package.json`
або запусти `START-WINDOWS.cmd`.

**Unknown learning timezone або UTC.** Виконай `npm run setup` і повтори запуск.

**python або npm is not recognized.** Перевір встановлення Python та Node.js.
Відкрий нове вікно CMD після встановлення.

**Address already in use.** Зупини попередній запуск через Ctrl+C.
Якщо порт зайнятий іншою програмою, перед `npm run dev` виконай
`set PORT=3002`. Тоді відкрий <http://localhost:3002>.

Якщо збій лишився, надішли скриншот з першими рядками помилки.
