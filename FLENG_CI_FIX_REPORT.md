# Fleng English — виправлення CI

Коміт із виправленнями — `22f0499`. Діагностика почалася з `79fc67d`.
Публічні метадані GitHub підтвердили результати завдань і кроки, що впали.
API повних журналів повернув HTTP 403. [Запуск GitHub Actions](https://github.com/Fleng-Fly/fleng-fly/actions/runs/46127933181)

## Першопричини

1. **SQLite and application та PostgreSQL integration.** Обидва завдання впали на
   повному pytest-наборі. У ньому залишався тест, який після повернення Reading
   вимагав `404` для `/reading.html` і `/js/reading.js` та відсутності посилання
   у workspace. Локально тест отримав `200`. Тепер він перевіряє доступність
   сторінки, трьох модулів і посилання в навігації. Перевірки `404` для старої
   сторінки статті, старого CSS та двох старих API залишилися.
2. **Static quality and dependency integrity.** У GitHub першим впав Ruff.
   Локально Ruff знайшов 15 порушень довжини рядка в імпортері CSV. Окремий
   запуск mypy виявив несумісність типів ключів словника рівнів. Після цих
   кроків перевірка документації виявила застарілий OpenAPI-опис
   `PlacementReview` і пропущене поле `CourseVocabularyItem.lexical_details`.
   Виправлено форматування, тип і документацію. Зафіксовані залежності та
   frozen lockfile пройшли перевірку.
3. **Required database checks.** Завдання агрегує статуси шести попередніх.
   У вихідному запуску три з них впали. Скрипт агрегатора відхилив ці статуси
   локально і повернув 0 на контрольному наборі з шести `success`.
4. **Локальне відтворення на Windows.** Додатково виправлено закриття SQLite
   перед прибиранням тимчасового файла, запуск перевірки документації через
   кросплатформний Python-лаунчер, читання UTF-8, складання шляху до основного
   checkout і порівняння абсолютних шляхів для Render. Тест резервної копії
   використовує допустиме на Windows ім'я з пробілом і `#` та перевіряє
   біти доступу на POSIX, як і раніше.

## Словник і цілісність даних

- Робоча SQLite, підрахунок у режимі читання — **1 599 унікальних
  нормалізованих слів** у 1 647 опублікованих записах. Точних рядкових значень
  `word` — 1 601.
- Свіжа тестова PostgreSQL 16 — **1 593 унікальні нормалізовані слова**
  у 1 641 опублікованому записі. Точних рядкових значень `word` — 1 595.
  Перший імпорт додав 581 слово до 1 012, повторний додав 0.
- Тест імпортера на SQLite пройшов валідацію, попередній перегляд, повторний
  імпорт і відкат. 25 000 записів у цьому тесті були синтетичними.
- Alembic upgrade, повторний upgrade, перевірки ORM, цілісності та зовнішніх
  ключів SQLite пройшли. Окремий запуск PostgreSQL перевірив міграції,
  збереження даних і словник. Підстав для зміни міграцій або SQL імпортера
  ці запуски не виявили.
